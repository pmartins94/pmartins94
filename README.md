## Hi there, I'm Paul 👋

🧭 I build digital products that works and performs for a living. When AI moved into every product roadmap, including mine, I got tired of arbitrating things I didn't really understand. So here I am!

___📓 This is a sketchbook, not a portfolio___

Each repo is an experiment with a simple goal, all built the same way:

- 🎯 what I set out to build
- 🔧 how it's actually put together
- 💥 where it broke, and why

The third part is the one I care about. An agent that handles routine work beautifully and falls apart on the 20% that needs real judgment teaches you more about designing AI products than any demo that works.

___Early days. Learning out loud on purpose.___
